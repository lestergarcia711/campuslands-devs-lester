## Ejercicio para practicar el hacer PRs(Pull Request de ejercicios)
## Alumno: Lester Garcia

### **Explicación General**
-Implementacion de un flujo de trabajo lineal y estructurado para la entrega de una tarea en un repositorio compartido, asegurando la trazabilidad del código y una comunicación clara con el equipo:

- Aislamiento en Rama Personal: Creamos una rama propia para trabajar de forma independiente sin interferir en el código de los demás.

- Desarrollo Centralizado: Añadimos la respuesta o código directamente en el archivo o directorio destinado a las resoluciones.

-Registro Local: Guardamos los cambios localmente mediante un commit para dejar constancia del avance.

- Publicación Remota: Subimos la rama local al repositorio en la nube para que esté disponible para revisión.

- Documentación del Pull Request (PR): Estructuramos una descripción formal para el PR que explica el objetivo del código, los cambios exactos realizados y las pruebas que validan que todo funciona correctamente.
